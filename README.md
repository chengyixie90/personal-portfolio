# 谢易宸个人作品集

完整作品集前台、实时预览编辑后台及 Vercel 保存和上传服务。保留六个项目、现有动画、响应式布局、简历下载和项目顺序调整。

## 部署

1. 使用 Node.js 24，运行 `npm ci` 和 `npm run build`。
2. 在 Vercel 导入本仓库。配置已在 `vercel.json` 中，构建输出为 `dist/client`。
3. 为项目连接一个 **private** Vercel Blob，区域建议东京 hnd1。使用平台提供的 OIDC 和 `BLOB_STORE_ID`，不要把存储凭据放进源码。
4. 保持预览部署启用 Vercel Authentication。仅给受保护的 `vercel-admin` 分支设置预览变量 `PORTFOLIO_PREVIEW_SETUP=1`。正式环境不能设置此变量。
5. 打开受保护预览的 `/admin`，由所有者亲自设置编辑密钥。
6. 给正式环境设置 `PORTFOLIO_RECOVERY_URL`，值为受保护预览的 `/admin?recover=1`，以便忘记密钥时恢复。部署正式环境。

正式网址通过 `/admin` 登录编辑；修改先存草稿，点击“发布草稿”才会展示给访客。首页页脚也保留隐蔽的管理入口。

## 内容与文件

`public/` 保存原有图片、视频、文档和页面模板；`editor/` 保存编辑器和渲染器；`api/site.js` 是 Vercel 服务入口。新上传的文件和数据库保存在私有 Blob，`/tmp` 仅用于每次请求的临时工作文件。数据库写入使用 ETag 条件更新，防止多个窗口覆盖；上传文件限制为 25 MB，大文件自动分段上传。

图片、PDF 和视频的公开访问由发布状态控制，未发布素材只允许已登录编辑者读取。保持 Blob 私有，不要将上传目录改为公共目录。未完成的上传分段可能暂留存储，可在维护时清理 `portfolio/chunks/` 中确认不再使用的文件。

## 从原站迁移

在原后台“发布记录”下载网站迁移备份。备份含草稿、发布记录、素材元数据，不包含登录密钥与会话。首次初始化时，可把备份 JSON 的 gzip/base64 内容设置为加密环境变量 `PORTFOLIO_MIGRATION_DATA`。它只用于初始化新数据库，后续不会覆盖已经保存的编辑内容。有上传素材时需另行迁移其原始文件。

备份和 `.env` 应单独妥善保存，不能提交到公开仓库。平台密钥由所有者自行设置。


此包的后台面向 Vercel。腾讯云静态托管只能使用前台静态导出，不能直接运行这里的后台。
