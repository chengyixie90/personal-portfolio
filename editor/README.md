# 作品集编辑后台

点击任意页面页脚的版权文字，或在网站网址后加 `/admin`，可进入编辑后台。首次由站点所有者设置 12–256 个字符的密钥；之后输入密钥进入。密钥只保存加盐校验值，不进入网页或源代码。登录 8 小时后需重新输入。后台顶部可修改密钥或退出；修改密钥会撤销其他设备的登录。忘记密钥时，使用站点所有者的 ChatGPT 身份重新设置。当前 Sites 版本仍保留外层的 ChatGPT 访问控制，未改变站点的分享范围。

后台打开即显示可编辑的作品页面，点文字在原位修改，点图片选择素材。左侧设置控制区块版式、顺序和动效。正式展示页读取最近一次发布。发布记录中的旧版本可恢复为草稿。

首页设置分为介绍、关于我、联系与简历三组，并支持与预览平滑同步滚动。个人照片可点击替换或上传；关于我的标题、姓名、标签、毕业信息、介绍和信息条目均可编辑，信息条目支持增删和排序。联系方式支持邮箱、电话、微信、网站／社交链接及文字，可增删和排序；较多联系方式在桌面分栏、手机纵向排列，沿用原联系区动效。旧版本的介绍、邮箱、电话等设置继续兼容，空白联系方式不会出现在正式页面。

顶部页面选择器的「项目排序」可拖动或按上移、下移排列全部项目，也可从首页设置点击「调整作品顺序」。排序先保存为草稿，发布后更新正式列表、编号与项目底部的下一项目链接。Vibe Coding 分类包括流形与留瞬，短视频广告默认在最后。旧内容文档首次读取时只补入留瞬并调整这三项的位置，保留原有字段、设置与素材；后续手动排序、删除及历史恢复均以用户保存的版本为准。

原有项目保存在 `public/*.html` 中。修改这些原始页面后，运行 `python3 editor/build.py` 更新已提交的 `editor/site-model.json`。新增区块使用统一排版和渐显，可在后台关闭渐显。原有项目的短网址和章节锚点在初始版本中保留。上传支持 MP4、WebM（单个 25 MB）及常用图片、PDF（单个 12 MB）。

开发时先执行 `node editor/build.mjs`，再用 Node.js 24 或更新版本运行 `node editor/local.mjs`，打开 `http://127.0.0.1:8766/admin`。本地检查的数据存储在被 Git 忽略的 `.editor-local` 中。正式发布使用 Sites Worker、D1 和 R2，运行环境需设置 `PORTFOLIO_OWNER_EMAIL` 为网站所有者的 ChatGPT 登录邮箱。

密钥校验使用 PBKDF2-SHA256（100,000 次）及随机盐。会话使用 32 字节随机令牌，数据库只保存令牌摘要；HTTPS 下 Cookie 设有 `__Host-`、`Secure`、`HttpOnly`、`SameSite=Strict`。登录接口限制尝试频率，所有写操作检查同源。页脚入口仅减少视觉干扰，实际权限始终在服务端检查。参考：[OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)、[Cloudflare Web Crypto](https://developers.cloudflare.com/workers/runtime-apis/web-crypto/)。

部署到 Vercel / 腾讯云前仍需接入对应的服务端、数据库、文件存储和所有者身份恢复方式；不能只上传静态文件便获得这套后台。
